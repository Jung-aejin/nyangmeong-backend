# 세션 마무리

1. `git status -sb`와 `git log --since=midnight --oneline`으로 이 세션에서 한 일을 모은다. 기억이 아니라 명령 출력을 근거로 쓴다.
2. `handoff/<이름>.md`(`<이름>`은 브랜치 이름, `/`가 있으면 앞부분)의 "지금 하는 것"을 결과로 바꾼다: 끝남 또는 진행 중, 그리고 한 줄 설명.
3. 남은 일은 "다음에 할 것"에 추가한다. 파일이 60줄을 넘으면 끝난 항목을 지우고, 지운 항목을 보고에 적는다. 핸드오프는 `/start`가 매번 통째로 읽으므로 짧게 쓴다.
4. `cp -R .claude/skills/. .agents/skills/` 다음 `diff -r .claude/skills .agents/skills`를 돌린다. 차이가 없어야 한다.
5. 커밋은 하지 않는다. 사용자가 원하면 `[이니셜] docs: 핸드오프 갱신`을 제안한다.
6. 보고: 바뀐 절, 동기화 결과, 확인하지 못한 것. 마지막 줄에 "다음 작업은 `/clear` 한 뒤 `/start`로 시작하세요"라고 적는다. 지금까지의 대화를 들고 다음 작업을 하면 그만큼 토큰을 계속 쓴다.

핸드오프는 공개 저장소에 커밋된다. 비밀값과 개인 PC 경로를 적지 않는다.
