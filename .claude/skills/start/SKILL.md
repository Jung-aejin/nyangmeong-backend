# 세션 시작

1. `git branch --show-current`로 브랜치를 본다. `develop`·`main`이면 "자기 이니셜 브랜치로 옮긴 뒤 다시 시작하세요"라고 말하고 멈춘다.
2. `<이름>`은 브랜치 이름(자기 이니셜, `/`가 있으면 앞부분)이다. `handoff/<이름>.md`가 없으면 `## 지금 하는 것`, `## 다음에 할 것` 두 절로 만든다.
3. 그 파일 전체를 읽는다. `AGENTS.md`는 세션을 시작할 때 이미 읽혀 있으므로 다시 읽지 않는다. `docs/convention/`은 작업이 가리킬 때 그 파일만 연다.
4. "다음에 할 것"에서 하나를 골라 완료 조건 1~2개와 함께 제안한다. 비어 있으면 `milestones/<이름>.md`에서 상태가 `대기`인 마일스톤 중 기다리는 것이 나온 맨 위 하나만 찾아 그 절만 읽고 제안한다. 그 파일도 없으면 `docs/convention/milestone.md`로 마일스톤부터 만들자고 제안한다.
5. 사용자가 고르면 "지금 하는 것"에 그 한 줄과 시작 시각을 적는다. 마일스톤에서 골랐으면 그 마일스톤의 상태를 `진행`으로 바꾼다.
6. 여기서 끝낸다. 코드는 쓰지 않는다.

핸드오프는 공개 저장소에 커밋된다. 비밀값과 개인 PC 경로를 적지 않는다.
